# BRAMO 1.0.0

Rilis stabil pertama BRAMO untuk Windows 10/11.

## Installer

- `BRAMO_1.0.0_x64-setup.exe` — installer NSIS, disarankan untuk kebanyakan pengguna.
- `BRAMO_1.0.0_x64_en-US.msi` — installer MSI.

## Sorotan

- Buddy visor LED interaktif dengan ekspresi, animasi, dan bubble kontekstual.
- Pomodoro, pengingat bio-rhythm, alarm, jadwal sholat, dan fitur fokus gaming.
- Kontrol musik, launcher, clipboard, file drop, dan pemantau sistem.
- BRAMO Journey dengan XP, level, aksesori, dan tema visor.
- Perbaikan posisi multi-monitor dan panel dropdown.

Installer resmi boleh dibagikan gratis. Penggunaan dan distribusi mengikuti [LICENSE](https://github.com/andikafadil28/bramo-app/blob/main/LICENSE).
