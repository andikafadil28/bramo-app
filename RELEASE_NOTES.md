# BRAMO 1.0.1

Pemeliharaan dan penyempurnaan desktop companion sejak rilis stabil 1.0.0.

## Perubahan

- Posisi window saat startup dibatasi ke area kerja monitor, lalu window ditampilkan dengan benar.
- Dropdown menyesuaikan arah saat BRAMO dekat bagian bawah layar; Settings memakai scroll internal.
- Dropdown dikunci saat Gaming Focus aktif dan ditutup saat game terdeteksi.
- Drag menggunakan perpindahan posisi terkontrol untuk mencegah Windows Aero Shake.
- Bubble pengingat azan memiliki tombol mute.

## Installer Windows

- `BRAMO_1.0.1_x64-setup.exe` — installer NSIS, disarankan untuk kebanyakan pengguna.
- `BRAMO_1.0.1_x64_en-US.msi` — installer MSI.

Installer ini **belum ditandatangani secara digital**. Windows dapat menampilkan peringatan SmartScreen untuk aplikasi/penerbit yang belum dikenal. Peringatan reputasi berbeda dari deteksi malware; jika antivirus menampilkan nama ancaman spesifik, jangan abaikan—laporkan ke maintainer untuk diperiksa.

Installer resmi boleh dibagikan gratis. Penggunaan dan distribusi mengikuti [LICENSE](https://github.com/andikafadil28/bramo-app/blob/main/LICENSE).

# BRAMO 1.0.0

## Pemeliharaan 1.0.1

- Posisi window saat startup dibatasi ke work area monitor, lalu window ditampilkan eksplisit.
- Dropdown flip ke atas saat BRAMO dekat bagian bawah layar; panel Settings memakai scroll internal.
- Dropdown dikunci ketika Gaming Focus aktif dan ditutup jika game mulai terdeteksi saat panel terbuka.
- Drag memakai perpindahan posisi terkontrol untuk menghindari Windows Aero Shake.

Rilis stabil pertama BRAMO untuk Windows 10/11.

## Installer

- `BRAMO_1.0.0_x64-setup.exe` — installer NSIS, disarankan untuk kebanyakan pengguna.
- `BRAMO_1.0.0_x64_en-US.msi` — installer MSI.

## Sorotan

- Buddy visor LED interaktif dengan ekspresi, animasi, dan bubble kontekstual.
- Pomodoro, pengingat bio-rhythm, alarm, jadwal sholat, dan fitur fokus gaming.
- Kontrol musik, launcher, clipboard, file drop, dan pemantau sistem.
- BRAMO Journey dengan XP, level, aksesori, dan tema visor.
- Perbaikan posisi multi-monitor dan panel dropdown.
