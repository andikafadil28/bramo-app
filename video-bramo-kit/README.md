# BRAMO — Video Kit

Delapan kartu visual vektor (SVG) 1280×720 dan catatan adegan untuk membantu menyusun video BRAMO dengan AI. Kartu dibuat berdasarkan fitur dan tampilan UI di source code. **Ini visual storyboard, bukan screenshot piksel langsung dari aplikasi.** Sesi ini tidak menyediakan capture native untuk jendela Tauri.

## Daftar visual

1. `01-bramo-buddy.svg` — companion desktop, drag/snap, dan karakter buddy.
2. `02-music-control.svg` — kontrol media sistem, now playing, dan music vibe.
3. `03-focus-pomodoro.svg` — sesi fokus/istirahat, mini timer, dan target XP harian.
4. `04-tools-launcher.svg` — system stats, file drop, clipboard, dan quick launcher.
5. `05-break-prayer.svg` — bio-rhythm break, jadwal salat, dan audio azan.
6. `06-visor-collection.svg` — XP, level, aksesori, koleksi, dan tema visor.
7. `07-living-animations.svg` — ekspresi mata/mulut, idle, musik, dan dizzy reaction.
8. `08-control-and-sleep.svg` — sleep/wake, autostart, fullscreen, dan power controls.

## Urutan video 45–60 detik

- **0–5 dtk — Hook:** BRAMO muncul di desktop. “Kenalin BRAMO, buddy kecil yang tinggal di desktop.”
- **5–13 dtk — Buddy hidup:** drag ke monitor lain, klik topi untuk snap, tunjukkan tatapan dan reaksi.
- **13–20 dtk — Musik dan tools:** tunjukkan player, stats, file drop, dan shortcut.
- **20–29 dtk — Fokus dan kesehatan:** Pomodoro, mini timer, pengingat jeda, dan jadwal salat.
- **29–38 dtk — Personal:** XP bertambah, buka koleksi, ganti mata/glow/tema.
- **38–48 dtk — Kepribadian:** mengetik, menggoyang kapsul, dan memutar musik.
- **48–55 dtk — Penutup:** sleep lalu wake. “BRAMO bukan cuma widget—dia buddy kecil yang nemenin rutinitasmu.”

## Prompt dasar AI video

> Buat video promo produk 16:9 bergaya cyberpunk lembut berdasarkan visual referensi BRAMO. Pertahankan bentuk kapsul visor LED hitam-cyan, topi pixel kecil, mata LED magenta/cyan, dan UI gelap. Gerakan halus dan ekspresif; jangan mengubah bentuk karakter atau menambahkan teks acak. Tampilkan adegan buddy desktop menyapa, kontrol musik, fokus Pomodoro, panel utilitas, koleksi XP/tema, reaksi animasi, lalu sleep/wake. Sisakan ruang untuk judul dan subtitle yang ditambahkan saat editing.

Untuk screenshot aplikasi yang benar-benar aktual, ambil capture dari jendela BRAMO setelah membuka setiap panel. Kartu SVG ini bisa dipakai sebagai storyboard atau visual referensi pendamping.
